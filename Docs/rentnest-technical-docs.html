🔐 Auth Flow
Complete registration → verification → login → token lifecycle
📝 Registration Flow
1
POST /signup-user or /signup-owner
User sends FirstName, LastName, Email, Password, Gender
RegisterDtoNo Auth
2
Password Hashed with BCrypt
Plain password is never stored — BCrypt.HashPassword() runs before saving
BCrypt
3
OTP Generated & Emailed
6-digit OTP generated, saved to DB with 10-minute expiry, sent via Gmail SMTP
MailKitExpiry: 10min
4
POST /verify-otp
User submits email + OTP → IsEmailVerified = true, OTP cleared
IsEmailVerified = true
5
Owner: Admin Approval Required
Owner accounts need SuperAdmin to set IsOwner = true before they can create properties
IsOwner = false until approved
🔑 Login & Token Flow
1
POST /signin-user
User sends Email + Password
LoginDtoNo Auth
2
3 Checks Before Login
① IsEmailVerified must be true ② IsActive must be true ③ BCrypt.Verify password
Fails → 401
3
JWT Access Token Generated
Contains: userId, email, role, name claims. Expires in 60 minutes
JWT · 60minHMAC SHA256
4
Refresh Token Saved
Cryptographically random token saved to DB with 7-day expiry
RefreshToken · 7 days
5
Angular Stores Token in localStorage
HttpInterceptor attaches Bearer token to every API request automatically
localStorageAuthorization: Bearer
📅 Reservation Flow
Complete lifecycle of a booking from creation to completion
1
Renter Creates Reservation
POST /reservations/create — Renter sends PropertyId, CheckInDate, CheckOutDate. System validates: ① No past dates ② Checkout after checkin ③ No overlapping confirmed bookings ④ Property is available
RenterOnlyStatus: PendingTotalAmount auto-calculated
2
Owner Confirms or Cancels
PUT /reservations/status — Owner can set status to Confirmed, Cancelled, or Completed
ConfirmedCancelledCompleted
3
Renter Can Cancel
PUT /reservations/status — Renter can ONLY set status to Cancelled (not Confirmed or Completed)
Cancelled only
4
Auto-Complete on Checkout
When fetching reservations, system checks: if CheckOutDate has passed AND status is Confirmed → automatically updates to Completed
Auto CompletedNo timer needed
5
Review Unlocked After Completion
Renter can submit a review ONLY when ReservationStatus = Completed. One review per reservation. Auto-updates property average rating.
Rating 1–5Property rating auto-updated
